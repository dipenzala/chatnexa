# ChatNexa — AI WhatsApp Business SaaS

India's first no-monthly-fee WhatsApp platform.

## Run
\`\`\`bash
bash chatnexa.sh
\`\`\`

Then edit \`backend/.env\` and \`frontend/.env.local\` with real keys.

- API → http://localhost:8080
- Web → http://localhost:3000

## Stack
Next.js 14 · React 18 · TS · Tailwind · Framer Motion · SWR · Recharts · Socket.IO
Node · Express · PostgreSQL (pgvector) · Redis · BullMQ · Meta WhatsApp API v19 · OpenAI · Cloudinary · Razorpay · Nodemailer · Exotel
